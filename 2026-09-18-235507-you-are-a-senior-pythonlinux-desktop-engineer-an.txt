  ## 1. Product concept                                                         
                                                                                
  Nido is a push-to-talk Persian voice assistant.                               
                                                                                
  The user presses and holds **F9**.                                            
                                                                                
  While F9 is held:                                                             
                                                                                
  * Nido captures microphone audio.                                             
  * A small visual overlay says that Nido is listening.                         
  * The microphone is actively recording only during the F9 hold.               
                                                                                
  When F9 is released:                                                          
                                                                                
  1. Stop recording.                                                            
  2. Convert/normalize the captured audio to the format required by Shenava.    
  3. Run Persian speech-to-text using Shenava Koochik.                          
  4. Show the recognized Persian text.                                          
  5. Translate Persian → English using a local Marian translation model         
  accelerated by CTranslate2.                                                   
  6. Send the English command to Needle 3.                                      
  7. Let Needle select one or more registered tools.                            
  8. Execute only those explicitly registered tools.                            
  9. Show the selected tool(s), arguments, execution result, and final status   
  in the UI.                                                                    
  10. Return to an idle state and wait for the next F9 press.                   
                                                                                
  Everything must work offline after model assets have been installed.          
                                                                                
  The runtime must not depend on a cloud API.                                   
                                                                                
  ---                                                                           
                                                                                
  # 2. Required model stack                                                     
                                                                                
  Use exactly this architecture:                                                
                                                                                
  Microphone                                                                    
  → Persian STT                                                                 
  → Persian→English translation                                                 
  → Needle 3 tool calling                                                       
  → local tool executor                                                         
                                                                                
  ### STT                                                                       
                                                                                
  Use:                                                                          
                                                                                
  `Reza2kn/Shenava-Koochik-v1.0`                                                
                                                                                
  For practical desktop inference, use the official deployment repository:      
                                                                                
  `Reza2kn/Shenava-Koochik-v1.0-sherpa-onnx`                                    
                                                                                
  Prefer the sherpa-onnx ONNX deployment rather than loading the raw NeMo       
  checkpoint directly.                                                          
                                                                                
  Important requirements:                                                       
                                                                                
  * 16 kHz                                                                      
  * mono audio                                                                  
  * float32 input to the recognizer                                             
  * offline inference                                                           
  * use the supplied tokenizer/tokens                                           
  * use the supplied Persian ITN when appropriate                               
  * do NOT enable per-feature normalization for this Shenava export             
  * keep all model files local after setup

● Built Nido: a lightweight, fully offline, push-to-talk Persian voice command
  assistant for KDE Plasma and Linux desktops.

  Architecture & Components

  1. Push-to-Talk Hotkey Subsystem (src/nido/hotkey/)
     - Protocol: HotkeyBackend(Protocol).
     - EvdevHotkeyBackend: reads Linux kernel input events directly via
       /dev/input/ to provide true push-to-talk across both Wayland and X11
       sessions.
     - Detects F9 down (1) to start capture, ignores key-repeat events (2),
       detects release (0) to end capture. Prevents duplicate release triggers.
     - Fallback MockHotkeyBackend for headless and test environments.
  2. Audio Capture & Normalization (src/nido/audio/)
     - AudioRecorder: captures in-memory float32 mono audio at 16,000 Hz.
     - Linear interpolation resampler for input devices running at 44.1 kHz / 48
       kHz.
     - Audio is kept strictly in volatile memory and discarded after inference.
  3. Persian Speech-to-Text (src/nido/stt/)
     - Protocol: SpeechRecognizer(Protocol).
     - ShenavaSherpaRecognizer: loads Reza2kn/Shenava-Koochik-v1.0-sherpa-onnx
       via sherpa-onnx.OfflineRecognizer (16 kHz, float32, mono, per-feature
       normalization disabled).
     - Built-in Persian Inverse Text Normalization (normalize_persian_numbers):
       normalizes words ("صفر", "ده", "بیست", "سی", "پنجاه", "صد", "سی و پنج")
       and Persian digits to standard ASCII integers.
  4. Persian → English Translation (src/nido/translation/)
     - Protocol: Translator(Protocol).
     - MarianCT2Translator: loads HPLT/translate-fa-en-v2.0-hplt_opus converted
       to CTranslate2 INT8 with SentencePiece tokenization. Reuses in-memory
       instance for greedy low-latency decoding.
     - Preserves technical entities (Chrome, Firefox, YouTube, Discord, GitHub,
       VS Code, Python, Docker).
  5. Needle 3 Command Router (src/nido/needle/)
     - NeedleCommandRouter: routes English commands to explicit structured tool
       calls using cactus-needle and registered tools.
     - Enforces NEEDLE_TELEMETRY=0 and DO_NOT_TRACK=1. Rejects arbitrary shell
       execution.
  6. Safe Tool Registry (src/nido/tools/)
     - apps.py: whitelisted application launcher and process killer (open_app,
       close_app).
     - browser.py: URL opener with scheme validation (http://, https://) and web
       search (open_url, search_web).
     - audio.py: volume control clamped to 0–100% using pactl, pamixer, or
       amixer (set_volume, increase_volume, decrease_volume, mute_volume,
       unmute_volume).
     - media.py: MPRIS media playback control via playerctl (play_pause,
       next_track, previous_track).
     - files.py: safe navigation using xdg-open (open_file, open_folder,
       find_files).
     - system.py: desktop utilities (take_screenshot, show_system_info,
       lock_screen). Destructive actions (shutdown, reboot) disabled by default.
  7. Pipeline Orchestrator (src/nido/pipeline.py)
     - Stages: IDLE → LISTENING → TRANSCRIBING → TRANSLATING → THINKING →
       EXECUTING → DONE / ERROR.
     - Publishes thread-safe PipelineEvent messages and tracks per-stage
       latencies.
  8. PySide6 Visual Overlay (src/nido/ui/)
     - NidoOverlay: frameless, always-on-top, translucent dark card in top-right
       screen corner.
     - PipelineWorker: QThread executing inference off the Qt GUI thread.
     - Displays heard Persian, translated English, active tool, result, and
       latency badge. Automatically hides after configurable timeout.
  9. Model Manager & Setup (src/nido/models/ & scripts/)
     - ModelManager: downloads and verifies local assets under
       ~/.local/share/nido/models/.
     - scripts/convert_translation_model.py: converts Marian models to
       CTranslate2 INT8.
     - scripts/install_autostart.py: installs systemd/nido.service and
       desktop/nido.desktop.
  10. Configuration & Logging (src/nido/config.py, src/nido/logging.py)
      - Configuration: ~/.config/nido/config.toml (XDG).
      - Logging: ~/.local/state/nido/nido.log (XDG). Never logs audio buffers.
  11. CLI & Diagnostic Suite (src/nido/cli.py)
      - nido (daemon + overlay)

      - nido tools list
